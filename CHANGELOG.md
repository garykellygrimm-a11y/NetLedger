# Changelog

All notable changes to NetLedger are documented in this file.

This project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html). Entries are generated by Knope from conventional commits and changeset files when a release is prepared; do not edit released sections by hand.
## 0.3.0 (2026-09-25)

### Breaking Changes

- enforce subnet containment and overlap rules in the database

### Features

- report containment and overlap violations as 400 and 409
- name the conflicting subnet and suggest a parent when creating subnets

## 0.2.0 (2026-09-25)

### Breaking Changes

- serve the API under the /api prefix

### Features

- list subnets in the web UI
- add a form to create subnets in the web UI
- Embed the built front end with rust-embed so release binaries serve the API and UI from one file. 
- serve the web UI from the server binary

### Fixes

- correct the charset and viewport tags in the web page

## 0.1.0 (2026-09-24)

### Features

- add subnet table migration
- connect to Postgres and apply embedded migrations on startup
- add subnet list and get endpoints
- add subnet creation with validation and JSON error responses
- add subnet deletion and API tests

### Fixes

- add DATABASE_URL to env template
- lowercase doc filenames to match their links
- stop suggesting reassignment when deleting a subnet with children
