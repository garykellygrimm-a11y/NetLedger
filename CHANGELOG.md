## 0.5.1 (2026-10-03)

### Features

- view, record, allocate, and delete addresses in the web UI

## 0.5.0 (2026-10-02)

### Features

- add the address table with containment and single-host rules
- record, list, and delete IP addresses with automatic subnet placement
- allocate the next free address in a subnet
- move addresses with their subnets when subnets are created or deleted

#### deleting a subnet moves its addresses to its parent

`DELETE /api/subnets/{id}` now moves the subnet's recorded addresses to its parent. It returns `409 Conflict` instead of deleting the subnet when the subnet has addresses but no parent, or when a moved address would become the parent's network or broadcast address. Delete or move those addresses first. Creating a subnet likewise moves the parent's addresses that fall inside it, and returns `409 Conflict` if one of them would become the new subnet's network or broadcast address.

## 0.4.1 (2026-09-30)

### Features

- show subnets as an indented tree in the web UI
- edit a subnet's name, description and VLAN in the web UI

## 0.4.0 (2026-09-30)

### Breaking Changes

- place subnets automatically and stop accepting parent_id
- release a deleted subnet's children to its parent instead of refusing the delete

### Features

- edit a subnet's name, description, and VLAN with PATCH
- drop the parent picker from the create form

## 0.3.1 (2026-09-25)

### Fixes

- return 409 instead of 500 when concurrent subnet creates deadlock

## 0.3.0 (2026-09-25)

### Breaking Changes

- enforce subnet containment and overlap rules in the database

### Features

- report containment and overlap violations as 400 and 409
- name the conflicting subnet and suggest a parent when creating subnets

## 0.2.0 (2026-09-25)

### Breaking Changes

- serve the API under the /api prefix

### Features

- list subnets in the web UI
- add a form to create subnets in the web UI
- delete subnets from the web UI
- serve the web UI from the server binary

### Fixes

- correct the charset and viewport tags in the web page

## 0.1.0 (2026-09-24)

### Features

- connect to Postgres and apply embedded migrations on startup
- add subnet list and get endpoints

### Fixes

- lowercase doc filenames to match their links
- stop suggesting reassignment when deleting a subnet with children
